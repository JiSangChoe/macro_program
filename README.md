# IO Macro v3

Windows에서 특정 프로그램 창을 대상으로 키보드와 마우스 동작을 자동 실행하는 WPF 매크로 프로그램입니다. 동작을 직접 조합하는 **수동 매크로**, 실제 입력을 기록하는 **녹화 매크로**, 저장된 여러 프로필을 묶어 실행하는 **통합 실행기**를 제공합니다.

> 이 프로그램은 Windows 전용입니다. 매크로 사용이 허용된 프로그램과 환경에서만 사용하세요. 대상 프로그램의 운영 정책이나 이용 약관을 먼저 확인해야 합니다.

## 주요 기능

- 실행 중인 창을 목록에서 선택하여 해당 창을 대상으로 매크로 실행
- 키보드 키 한 개 또는 여러 키의 동시 입력
- 마우스 이동 및 왼쪽 클릭
- 키 누름 시간, 동작 후 대기 시간, 개별 동작 반복 횟수 설정
- 키보드와 마우스 입력 실시간 녹화
  - 키 누름/해제
  - 마우스 이동
  - 왼쪽 버튼 누름/해제
  - 휠 스크롤
- 수동/녹화 매크로 프로필 저장, 불러오기, 삭제
- 여러 프로필을 순서대로 또는 무작위 순서로 실행
- 전체 반복 실행 및 일시정지
- 대상 창의 포커스가 사라지면 자동 일시정지
- 설정한 대기 시간에 ±12% 범위의 무작위 편차 적용 가능

## 실행 환경

- 운영체제: Windows
- 프레임워크: .NET 10
- UI: WPF
- 별도 NuGet 패키지: 없음

소스에서 실행하려면 [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)이 필요합니다. 이미 배포된 `key_macro.exe`를 사용하는 경우 해당 실행 파일의 배포 방식에 따라 .NET Desktop Runtime이 필요할 수 있습니다.

## 빠른 시작

저장소 루트의 `key_macro.exe`를 실행하거나, 소스 코드로 다음 명령을 실행합니다.

```powershell
dotnet run --project .\key_macro\key_macro.csproj
```

프로그램이 열리면 다음 순서로 사용합니다.

1. 상단의 **대상 윈도우 선택**에서 입력을 보낼 프로그램을 선택합니다.
2. **수동 매크로 설정** 탭에서 동작을 만들거나, **키 입력 실시간 녹화** 탭에서 입력을 녹화합니다.
3. 프로필 이름을 입력한 뒤 **프로필 저장**을 누릅니다.
4. 저장한 프로필을 불러오거나 **통합 매크로 실행기**의 실행 순서에 추가합니다.
5. **매크로 실행**을 누르거나 `Ctrl+F3`을 입력합니다.

창을 연 뒤 대상 프로그램이 목록에 없다면 **새로고침**을 누르세요.

## 수동 매크로 만들기

**수동 매크로 설정** 탭에서 아래 동작을 추가할 수 있습니다.

### 키보드 입력

1. 동작 구분에서 **키보드 입력**을 선택합니다.
2. 키 입력란을 클릭하고 원하는 키를 누릅니다. 여러 키를 누르면 조합 입력으로 저장됩니다.
3. 키를 누르고 있을 시간, 반복 횟수, 동작 후 대기 시간을 입력합니다.
4. **동작 추가**를 누릅니다.

### 마우스 클릭 또는 이동

1. 동작 구분에서 **마우스 클릭** 또는 **마우스 이동**을 선택합니다.
2. 대상 창을 기준으로 한 X, Y 상대 좌표를 입력합니다.
3. 좌표를 직접 찾으려면 대상 창 위에 마우스를 올리고 `Ctrl+F6`을 누릅니다.
4. 반복 횟수와 동작 후 대기 시간을 설정하고 동작을 추가합니다.

목록에 추가된 동작은 순서를 위아래로 변경하거나, 선택하여 수정·삭제할 수 있습니다.

> 현재 화면 안내 일부에는 좌표 선택 키가 `F8`로 표시되지만, 실제 소스에 등록된 단축키는 `Ctrl+F6`입니다.

## 입력 녹화

1. **키 입력 실시간 녹화** 탭을 엽니다.
2. 녹화할 항목에서 키보드와 마우스를 선택합니다.
3. 녹화 대상 창을 선택합니다.
4. **녹화 시작** 또는 `Ctrl+F1`을 누릅니다.
5. 대상 창에서 원하는 작업을 수행합니다.
6. **녹화 중지 및 저장** 또는 `Ctrl+F2`를 누릅니다.
7. 프로필 이름을 입력하고 저장합니다.

한 번의 녹화는 최대 10분입니다. 마우스 이동 이벤트는 데이터가 지나치게 많아지는 것을 방지하기 위해 직전 기록 지점에서 X, Y 모두 8픽셀 미만으로 움직인 경우 생략됩니다.

## 통합 매크로 실행기

저장된 수동 매크로와 녹화 매크로를 하나의 실행 목록으로 조합할 수 있습니다.

- **순서대로 반복 실행**: 목록의 위에서 아래 순서로 실행
- **무작위 반복 실행**: 실행할 때마다 프로필 순서를 섞어서 실행
- **반복**: 중지할 때까지 전체 실행 목록을 반복

실행 목록의 항목은 추가, 제거, 위로 이동, 아래로 이동할 수 있습니다.

## 단축키

| 단축키 | 기능 |
|---|---|
| `Ctrl+F1` | 입력 녹화 시작 |
| `Ctrl+F2` | 입력 녹화 중지 |
| `Ctrl+F3` | 매크로 실행 |
| `Ctrl+F4` | 실행 일시정지/이어하기 |
| `Ctrl+F5` | 매크로 실행 중지 |
| `Ctrl+F6` | 현재 마우스 위치를 대상 창 기준 상대 좌표로 가져오기 |

단축키는 Windows 전역 단축키로 등록됩니다. 다른 프로그램이 같은 단축키를 먼저 사용 중이면 정상 동작하지 않을 수 있습니다.

## 프로필 저장 위치

프로필은 실행 파일이 있는 폴더를 기준으로 아래 경로에 JSON 형식으로 저장됩니다.

```text
saves\profiles.json
```

프로필을 백업하려면 `saves` 폴더를 복사하면 됩니다. 프로그램이 해당 폴더에 파일을 만들 수 있어야 하므로, 쓰기 권한이 없는 위치에서는 프로필 저장이 실패할 수 있습니다.

## 빌드 및 배포

### Release 빌드

```powershell
dotnet build .\key_macro\key_macro.csproj -c Release
```

빌드 결과는 기본적으로 다음 폴더에 생성됩니다.

```text
key_macro\bin\Release\net10.0-windows\
```

### 프레임워크 종속 배포

```powershell
dotnet publish .\key_macro\key_macro.csproj -c Release -r win-x64 --self-contained false
```

### 단일 실행 파일로 배포

대상 PC에 .NET Desktop Runtime을 별도로 설치하지 않으려면 자체 포함 배포를 사용할 수 있습니다.

```powershell
dotnet publish .\key_macro\key_macro.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

## 동작 방식과 주의사항

- 키보드와 마우스 입력은 Windows `SendInput` API로 전송됩니다.
- 실시간 녹화는 Windows 저수준 전역 키보드/마우스 훅을 사용합니다.
- 매크로 실행을 시작하면 선택한 대상 창을 전면으로 가져옵니다.
- 실행 도중 대상 창이 포커스를 잃으면 눌린 키를 해제하고 자동으로 대기합니다. 대상 창으로 돌아오면 실행을 이어갑니다.
- 마우스 좌표는 대상 창의 바깥쪽 좌상단을 `(0, 0)`으로 하는 상대 좌표입니다. 창을 이동해도 같은 상대 위치를 사용하지만, 창 크기나 UI 배치가 달라지면 의도한 위치와 어긋날 수 있습니다.
- 관리자 권한으로 실행된 프로그램에는 일반 권한으로 실행한 이 프로그램이 입력을 전달하지 못할 수 있습니다. 필요한 경우 두 프로그램의 권한 수준을 동일하게 맞추세요.
- 녹화 중에는 비밀번호나 개인정보를 입력하지 마세요. 녹화한 키 이벤트는 프로필 JSON 파일에 저장될 수 있습니다.

## 프로젝트 구조

```text
macro_program/
├─ key_macro.exe                 # 배포된 실행 파일
├─ README.md
└─ key_macro/
   ├─ key_macro.csproj           # .NET/WPF 프로젝트 설정
   ├─ App.xaml                   # 애플리케이션 시작점
   ├─ MainWindow.xaml            # 메인 화면
   ├─ MainWindow.xaml.cs         # UI 이벤트 및 매크로 실행 로직
   ├─ MacroAction.cs             # 수동 매크로 동작 모델
   ├─ MacroProfile.cs            # 프로필 모델
   ├─ MacroRecorder.cs           # 키보드/마우스 녹화
   ├─ ProfileManager.cs          # JSON 프로필 저장 및 불러오기
   ├─ Win32Api.cs                # Windows API 선언
   └─ InputDialog.xaml           # 프로필 이름 입력 창
```

## 알려진 제한사항

- Windows 이외의 운영체제에서는 실행할 수 없습니다.
- 녹화 가능한 마우스 버튼은 현재 왼쪽 버튼뿐입니다. 오른쪽/가운데 버튼은 기록하지 않습니다.
- 녹화 프로필에는 동작 편집 UI가 없으며, 재녹화하거나 `profiles.json`을 직접 수정해야 합니다.
- 프로필 파일 읽기/쓰기 오류는 디버그 출력으로만 기록되므로 화면에 상세 오류가 표시되지 않습니다.
- 녹화 프로필의 화면상 예상 시간은 이벤트 간 지연 시간의 합계이며 실제 실행 시간은 시스템 상태에 따라 조금 달라질 수 있습니다.
